## 3. 上位陣に欠けている要素（＝差別化点）

1. **大学（NCAA系）とNFLで処置が違う反則を明示したページがほとんどない**。守備側パス・インターフェアランスは大学ルールでは「15ヤード＋自動ファーストダウン」だがNFLは反則地点からのファーストダウン。ターゲティングはNCAA系で「15ヤード＋資格没収」。上位でこの差に正面から触れているのはWikipediaのみで、観戦者向けの説明にはなっていない。
2. **日本の規則（JAFA）としての一次情報を出典に使っているページが0件**。日本アメリカンフットボール協会が公開している「[アメリカンフットボール公式規則変更の歴史](https://americanfootball.jp/history/5605)」には、ターゲティングの資格没収強化（2013年度）、同一シーズン3回目以降の出場停止（2019年度）、資格没収選手のチームエリア残留可（2020年度）、ホールディングの15→10ヤード（1981年度）など、日本で実際に適用されてきた改定が年度つきで載っているが、SERP上位のどのページもこれを参照していない。
3. **「罰則＝ヤード罰退だけではない」という構造の説明が弱い**。second-effortのみが5分類を提示。他は罰退ヤード一覧で終わっており、ロス オブ ダウン・自動ファーストダウン・資格没収が混在していることを整理していない。
4. **反則の「受諾／辞退（ディクライン）」に触れたページが少ない**。反則が宣告されても罰則が適用されない場面がある理由を説明できているページは上位にほぼない。
5. **関東学生リーグ（KCFA）の文脈がゼロ**。大学部の公式サイトが上位に来ている＝大学生・大学アメフトの読者が一定数いるのに、リーグの実データに接続した解説は存在しない。

## 4. 本記事の差別化施策

- **「大学ルールとNFLで処置が違う反則」を独立したH2で扱う**（守備側パス・インターフェアランス、ターゲティング、フェイスマスク）。上位で観戦者向けにこれを整理した記事がないため、本記事だけの要素になる。
- **JAFA公式「アメリカンフットボール公式規則変更の歴史」を出典に、日本で適用されてきた反則規定の改定を年度つきで紹介する**。日本の一次情報を使った反則解説は上位10件に存在しない。
- **罰則を「罰退ヤード」だけでなく5つの型で整理する**（ヤード罰退／ロス オブ ダウン／自動ファーストダウン／10秒減算／資格没収）。

## 6. 注意点（執筆時の判断）

- **JAFA公式規則書PDF（2026〜27年度版・2024〜25年度版）は画像ベースで本文抽出不可**（タイブレーク記事のときと同じ状況）。条文番号の引用は行わず、「細目は公式規則書による」として参照リンクに留める。
- **罰退ヤードの区分が出典間で割れる項目がある**。「背後へのブロック（ブロック・イン・ザ・バック）」はWikipediaが15ヤード区分、second-effortが10ヤード区分に置いている。記事では10ヤードとして扱いつつ、区分は出典により異なりうる旨と最終的には公式規則書による旨を注記する。「不正なフォワードパス」も同様にWikipedia内で記述が揺れているため表から外した。
- **特定の試合で特定の反則が何回あったか、勝敗を分けたかというプレー単位のデータは取得できていない**。捏造防止のため、記事では「反則が試合結果を左右した」と断定する記述を書かない。関東TOP8の僅差の事実（2025年8月30日の立教大学対東京大学＝規定時間17-17からタイブレークで東京大学が勝利）は、反則と紐づけず「僅差の試合が実在する」文脈でのみ使う。
- KCFA公式サイトには競技規則そのもののページが見当たらず、掲載があるのは安全・安心マニュアル（日本学生協会）のみ。KCFAがJAFA規則を採用している旨の明記は確認できなかったため、「KCFAがJAFA規則を採用している」とは書かない。
