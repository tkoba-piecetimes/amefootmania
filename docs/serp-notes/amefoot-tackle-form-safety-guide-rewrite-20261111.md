## 4. 上位・関連ページにあって自記事にない要素

1. タックル手順の具体性（構え→間合い→踏み込み→ラップ→足を動かし続ける、のチェックリスト形式）。自記事は2段落のみで、出典がない一般論。
2. 「やってはいけない当たり方」（ヘッドダウン、頭頂部、ヘルメット先行）の明示と、その理由（頸椎がまっすぐになる）。JAFAハンドブックp.15に図つきの説明がある。
3. 事故が起きやすい状況（初心者、高校1年・大学1〜2年、夏合宿、疲労時、不意のタックル、スキルポジション）。JAFAハンドブックp.12。
4. HUT（Heads Up Tackling）という名前と、国内での検証結果（体育学研究2017）。
5. 当たり方を覚える段階づけ（いきなりフルコンタクトをしない）。JAFAハンドブックp.13、2026-08-25緊急告知【下級生】【少人数のチーム】。
6. ターゲティング（頭頂部で相手を痛めつけるヒット）の反則。JAFA「頚部外傷とその予防」 https://americanfootball.jp/top_news/150/
7. FAQ（怖い・首を痛めない方法・何年目から当たるか等）。

## 7. 差別化の方針（意図は変えない）

- JAFA資料の「なぜ頭から当たると危ないか（頸椎のカーブ）」と「事故が起きやすい状況」を、新入部員向けのチェックリストに落とす。
- HUTの国内検証（体育学研究2017）を「安全な当たり方は弱いタックルではない」根拠として1段落で使う。
- 2026年の緊急告知（8月・下級生・少人数チーム）を、入部1年目の過ごし方に接続する。
- 首の鍛え方・反則一覧・入部ガイド・熱中症・ヘルメット記事へ内部リンクを張り、「怪我と予防」クラスタの技術ハブにする。
