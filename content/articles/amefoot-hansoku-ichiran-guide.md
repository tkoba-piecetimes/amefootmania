大学アメフトの試合を見ていると、プレーの途中で黄色いフラッグがグラウンドに投げ込まれ、そのまま試合が止まる場面に出会います。アナウンスで反則名が読み上げられても、意味がわからないまま次のプレーが始まってしまうことがあります。この記事では、反則の種類と、その処置（罰則）がどのように決まっているのかを、種類ごとに整理して解説します。

## アメフトの反則と罰則の基本

反則は「罰退ヤード」の大きさだけで決まるのではなく、罰退に加えてダウンの扱いが変わるものがあります。

反則が起きると、審判がイエローフラッグを投げてこれを知らせます。フラッグが投げられてもプレーはそこで止まらず、最後まで進んだうえで、プレー終了後に反則の宣告と処置が行われます。

処置の内容は、罰退ヤードの距離だけで決まるわけではありません。ダウンをやり直すのか、攻撃権が移るのか、選手がその試合に出られなくなるのか、といった要素まで含めて決まります。

日本の学生の試合で用いられている競技規則は、[日本アメリカンフットボール協会の公式規則書](https://americanfootball.jp/rule)が定めています。同協会のサイトでは、2026〜27年度版の公式規則書と「2026公式規則変更内容決定報」が公開されており、規則は毎年見直される前提のものであることがわかります。

この記事は観戦や入部の際に役立つ範囲での整理であり、条文の細かい適用条件は公式規則書によります。

## 罰則は5つの型に分かれる

罰則は罰退ヤードだけでなく、5つの型の組み合わせで理解すると読み解きやすくなります。

1. **ヤードの罰退（5／10／15ヤード）**: 最も基本的な処置で、反則の重さに応じて5・10・15ヤードのいずれかが罰退として与えられます。
2. **ロス オブ ダウン**: 罰退に加えてダウンを1つ失う処置で、主に攻撃側の一部の反則に適用されます。
3. **自動ファーストダウン**: 罰退に加えて攻撃側に新しいファーストダウンが与えられる処置で、主に守備側の反則に適用されます。
4. **時計の10秒消費**: 前半・後半の終盤に、時計を止める目的があったとみなされる反則があった場合の措置です。
5. **資格没収**: その試合に出場できなくなる処置で、ターゲティングなど安全に関わる反則に適用されます。

反則の解説というと罰退ヤードの一覧だけで終わっているものも見かけますが、実際の処置は罰退ヤードとこの5つの型の組み合わせで決まる場合があります。ヤード数だけを覚えるより、この5つの型とセットで押さえておくと、アナウンスの内容を理解しやすくなります。

## 罰退ヤード別の反則一覧

反則は罰退ヤードの大きさによって、おおまかに5ヤード・10ヤード・15ヤードの3段階に分けて整理できます。

### 5ヤードの反則

| 反則名 | 英語・カナ表記 | どんな行為か |
| --- | --- | --- |
| フォルス・スタート | False Start | スナップ前に攻撃側の選手が動いてしまう反則 |
| オフサイド | Offside | スナップ前に守備側の選手がラインを越えている反則 |
| エンクローチメント | Encroachment | スナップ前に相手側の陣地に体が入り込む反則 |
| ディレイ オブ ゲーム | Delay of Game | プレークロックが切れる前にスナップできない反則 |
| イリーガル・モーション | Illegal Motion | スナップ前の選手の動き方が規則に反する反則 |
| イリーガル・シフト | Illegal Shift | フォーメーション変更後の静止が守られない反則 |
| イリーガル・フォーメーション | Illegal Formation | スナップ時の選手配置が規則に反する反則 |
| 交代違反 | Illegal Substitution | 選手交代の手続きが規則に反する反則 |

5ヤードの反則の多くは、スナップ前の動きや隊形に関するもので、得点やビッグプレーに直接つながる場面は多くありません。一方で、攻撃のテンポを乱す要因にはなりやすく、フォルス・スタートやディレイ オブ ゲームは、観客席からもフラッグのタイミングで気づきやすい反則です。

### 10ヤードの反則

| 反則名 | 英語・カナ表記 | どんな行為か |
| --- | --- | --- |
| ホールディング（攻撃側） | Offensive Holding | 攻撃側の選手が相手を手や腕で抱え込むように止める反則 |
| ブロック・イン・ザ・バック | Block in the Back | 相手の背後を手で押すようにブロックする反則 |
| イリーガル ユース オブ ハンズ | Illegal Use of Hands | 手の使い方が規則に反するブロック・ディフェンス |
| 無資格レシーバーのダウンフィールドへの進出 | Ineligible Receiver Downfield | パスプレーで進出資格のない選手がラインより先に出る反則 |

10ヤードの反則は、攻撃側のブロックに関するものが中心です。とくにホールディングはプレーの流れを大きく止める反則として扱われ、得点やビッグプレーの直後に宣告されると、その結果が打ち消される場合があります。

### 15ヤードの反則

| 反則名 | 英語・カナ表記 | どんな行為か |
| --- | --- | --- |
| パーソナル・ファウル | Personal Foul | 選手の安全に関わる危険な行為全般を指す総称 |
| ラフィング・ザ・パサー | Roughing the Passer | パスを投げ終えたQBに対する過度な接触 |
| ラフィング・ザ・キッカー | Roughing the Kicker | キックを終えたキッカーに対する過度な接触 |
| フェイス・マスク | Face Mask | 相手のフェイスマスクをつかむ・引っ張る行為 |
| ホースカラータックル | Horse-Collar Tackle | 肩パッドの内側や襟をつかんで引き倒すタックル |
| クリッピング | Clipping | 相手の後方から膝より下をブロックする行為 |
| 腰より下へのブロック | Low Block | 隊形によっては認められない、腰より低い位置へのブロック |
| チョップ・ブロック | Chop Block | 上下から同時に相手を挟むように行うブロック |
| アンスポーツマンライク・コンダクト | Unsportsmanlike Conduct | スポーツマンらしくない行為全般 |
| ターゲティング | Targeting | 無防備な選手の頭・首を狙った危険な接触 |

15ヤードの反則には、選手の安全に関わるものが多く含まれています。パーソナル・ファウルは個別の行為名というより総称として使われ、ラフィング・ザ・パサーやフェイス・マスクなど、より具体的な反則名がその中に含まれる形で運用されています。

なお、罰退ヤードの区分は出典によって異なる場合があり、最終的な適用は公式規則書によります。たとえばブロック・イン・ザ・バックは、資料によって10ヤードの反則として紹介される場合と、15ヤードの反則として紹介される場合があります。[Wikipediaの反則一覧](https://ja.wikipedia.org/wiki/アメリカンフットボールの反則)では10ヤードに分類されており、この記事の分類と一致していますが、他の資料と照合する際は、区分が資料ごとに揺れる場合がある点にご注意ください。

## 大学ルールとNFLで処置が違う反則

同じ名前の反則でも、大学（NCAA系）の規則とNFLでは処置が異なるものがあります。

**守備側パス・インターフェアランス**は、大学の規則では罰退に上限があり、反則が起きた地点が15ヤードを超えて離れている場合は、15ヤード地点からの攻撃側ファーストダウンになります。NFLは距離に関係なく反則が起きた地点からのファーストダウンとなるため、1回の反則で数十ヤード進む場合があります。日本の規則でも1984年度の改定でこの上限付きの形に変わったことが、[アメリカンフットボール公式規則変更の歴史](https://americanfootball.jp/history/5605)に記録されています。

**ターゲティング**は、無防備な状態の選手の頭・首への危険な接触に適用され、15ヤードの罰退に加えて資格没収（その試合の出場停止）を伴います。NFLにも危険なタックルを取り締まる反則はありますが、資格没収が自動的にセットになっている点は、大学系ルールの特徴です。

なお、攻撃側パス・インターフェアランスについては、日本の規則では1993年度にロス オブ ダウンが削除され、15ヤードの罰則のみになった、という改定が行われています。

## 日本の規則で反則の扱いはこう変わってきた

反則の罰則は固定されたものではなく、安全性と競技の公平性の観点から改定が重ねられてきました。[アメリカンフットボール公式規則変更の歴史](https://americanfootball.jp/history/5605)には、次のような改定が記録されています。

- **1981年度**: ホールディングの罰則が15ヤードから10ヤードへ変更されました。
- **1984年度**: 守備側パス・インターフェアランスの罰則が、反則地点でのファーストダウンから、15ヤード以上離れた地点での反則は15ヤード地点でのファーストダウンへと変更されました。
- **1993年度**: 攻撃側パス・インターフェアランスからロス オブ ダウンが削除され、15ヤードの罰則のみになりました。
- **2013年度**: 無防備な選手への接触に関する規定が強化され、反則した選手は自動的に資格没収となる扱いになりました。後半での反則は、次の試合の前半も出場停止になります。
- **2019年度**: 同一シーズンで3回目以降のターゲティングは、その試合と次の試合の出場停止になりました。
- **2020年度**: 資格没収となった選手が、退場せずチームエリアに留まれるよう変更されました。

こうした安全面に関わる規則改定は、現場の運用にも反映されています。関東学生アメリカンフットボール連盟（KCFA）が掲載する[安全・安心マニュアル](https://www.kcfa.jp/safety/)（日本学生協会作成）でも、選手の安全確保に関する内容がまとめられています。

## 反則が宣告されても罰則が適用されないことがある

反則の罰則を受けるかどうかは反則されなかった側が選べるため、宣告されても罰則が適用されない場面があります。

反則の罰則には、受諾（アクセプト）と辞退（ディクライン）という2つの選択肢があります。反則されなかった側のチームが、そのプレーの結果と罰則の内容を比べて、どちらか有利な方を選ぶ仕組みです。

たとえば守備側の反則があっても、そのプレーで攻撃側が反則の罰退ヤードより長く前進してファーストダウンを更新していた場合、罰則を受諾するより、プレーの結果をそのまま残す方が有利になる場合があります。このようなときは、罰則を辞退してプレーの結果を採用することになります。

そのため、反則の数が多いことがそのまま不利につながるとは限りません。プレーの結果と罰則の内容を比較したうえで、有利な方が選ばれる仕組みになっているためです。

観戦しているときにアナウンスで「ディクライン」「辞退」という語が聞こえたら、その反則によるプレーのやり直しは行われず、プレーの結果がそのまま残った、という意味になります。反則が宣告された直後にもう一度アナウンスが入る場合は、この受諾・辞退の判断が案内されていることが多く、注意して聞くと展開を追いやすくなります。

## 関東学生リーグで反則の場面を見るには

実際の試合で反則の場面を確認するには、日程と順位表から観戦する試合を選ぶのが近道です。

反則の宣告や処置は、関東学生アメリカンフットボール連盟（[KCFA](https://www.kcfa.jp/)）が運営するTOP8・BIG8の試合でも見られます。まずは[TOP8の日程・結果](../../top8/schedule/index.html)や[BIG8の日程・結果](../../big8/schedule/index.html)から、直近の試合を確認してみてください。

[関東TOP8の順位表](../../top8/standings/index.html)や[BIG8の順位表](../../big8/standings/index.html)で上位チーム同士の対戦を選ぶと、僅差の展開になりやすく、反則の1つがドライブの流れを変える場面に出会いやすくなります。もっとも、反則そのものが勝敗を決めたと言い切れるものではなく、あくまで試合展開のひとつの要素として見るのがよいでしょう。

接戦の末に同点で試合が終わった場合、どのように決着するかは、[アメフトのタイブレークのルール](../amefoot-tiebreak-rule-guide/index.html)で解説しています。また、勝ち点や順位の並び方は[関東学生アメフトリーグの順位表の見方](../kanto-amefoot-junihyo-guide/index.html)を参照してください。

反則の前提となる試合時間やダウン制など基本のルールは、[大学アメフトの試合時間とルール入門](../american-football-watching-guide/index.html)にまとめています。あわせて確認すると、反則が起きた場面の状況を理解しやすくなります。チームごとの成績や記録は[TOP8の記録室](../../top8/records/index.html)でも確認できます。

## まとめ

- 反則は罰退ヤードだけでなく、ロス オブ ダウン・自動ファーストダウン・時計の10秒消費・資格没収を含めた5つの型の組み合わせで処置が決まります
- 罰退ヤードは主に5・10・15ヤードに分かれており、反則の性質によって区分されています
- 守備側パス・インターフェアランスやターゲティングのように、大学ルールとNFLで処置が異なる反則があります
- 日本の規則も、1981年度以降、安全性や公平性の観点から複数回の改定が重ねられてきました
- 反則には受諾（アクセプト）と辞退（ディクライン）という選択肢があり、宣告されても罰則が適用されない場合があります
- 条文の細かい適用条件は、[日本アメリカンフットボール協会の公式規則書](https://americanfootball.jp/rule)によります

反則の種類と処置の型を押さえておくと、フラッグが飛んだ場面でも、次に何が起こるのかを見通しやすくなります。
