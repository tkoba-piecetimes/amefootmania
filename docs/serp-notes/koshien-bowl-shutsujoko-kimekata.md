## 共通点（検索意図の正解）

1. 読者が知りたいのは「**どうやって出場校が決まるのか＝仕組みの説明**」。出場校名の一覧ではなく、決定プロセスの手順が求められている。
2. 上位を満たすには「出場枠の内訳」と「トーナメントの構造」の2点を押さえる必要がある。この2点は Wikipedia と 1st down が部分的にカバーしている。
3. **主クエリのSERP 1ページ目はほぼ全部が高校野球（センバツ・夏の甲子園）の記事**で、アメフトの甲子園ボウルを扱っているのは Wikipedia 1件のみ。検索意図とSERPが大きくずれており、アメフト側から正面で答える記事の空きが大きい。

## 上位陣に欠けている要素（差別化点）

1. **関東代表3校が決まる過程の説明がゼロ**。全サイトが「TOP8の3位まで」で止まっており、同じ勝ち点で並んだ場合にどう決まるかを書いているサイトが見つからなかった。KCFAは「順位順列決定方法」（https://www.kcfa.jp/rankingmethod/ ）で**6段階のタイブレーク基準**を公表しており、これを段階ごとに解説できる。
2. **「順位（勝ち点順）」と「順列（タイブレーク後の確定順位）」の区別**。KCFAの星取表はこの2つを別の列として公表しており、代表3校を左右するのは後者。本サイトはこの構造をデータ取得の実装レベルで把握している（README「データソースの詳細」）。
3. **関東1位・2位・3位で準々決勝の相手が変わるという構造**。2025年度（第80回）の公式トーナメント表では関東3校すべてが準々決勝から登場し、1位は地方代表の勝ち上がりチーム、2位は関西3位、3位は関西2位と対戦していた。「3位でも出られる」で終わらせず、順位の重みを具体的に示せる。
4. **ラウンドごとに違う同点処理**。準決勝までは同点ならタイブレークシステム→なお決しなければ抽選、決勝（甲子園ボウル）だけはタイブレークを行わず両校優勝。この規定に触れている競合記事は見つからなかった。
5. **2026年度が新方式の3年目にあたる**という時間軸。KCFA告知は「3年間は新方式で実施する」としており、現行方式が期間限定の試行であることを説明している記事がない。
6. **自サイトの一次データページ**（TOP8の順位表・日程・記録室・チーム一覧）への内部リンク。競合が持たない資産。
