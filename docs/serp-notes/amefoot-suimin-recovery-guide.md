# SERPメモ: アメフト 睡眠 リカバリー（2026-11-13）

- 検索意図: 部員が「練習・試合の疲れを取るために、睡眠をどう整えるか」を知りたい。上位は睡眠一般論、スポーツ栄養サイト、海外の学生アスリート睡眠記事（Sleep Foundation等）、競技者向けNSCA Japan総説が中心。
- 共通点: 睡眠時間の目安、就寝前スマホ・カフェインの注意、昼寝、睡眠の質の話。アメフト固有（防具・高強度・秋季リーグ戦の週間リズム）に寄せた記事は見当たらない。
- 差別化: 厚生労働省「健康づくりのための睡眠ガイド2023」とNSCA Japan総説（Bird 2016）の一次情報だけで構成し、アメフトの練習日・試合週の組み立てに落とす。アメフト選手を直接対象にした睡眠研究は確認できていないため、その旨を明記して断定を避ける。データページ（TOP8/BIG8 日程）への導線を付ける。
