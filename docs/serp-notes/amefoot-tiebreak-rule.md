## 2. 共通点（＝検索意図の正解）

1. 「第4クォーター終了時に同点だったらどうなるのか」に最初に答えている。
2. NFL（サドンデス系）と大学・日本（タイ・ブレイク・システム）の違いを対比で説明している。
3. 手順は「コイントス → 敵陣25ヤードから攻撃 → 表裏を終えて得点の多い方が勝ち → 同点なら繰り返し」の4点セット。

## 3. 上位陣に欠けている要素（＝差別化点）

1. **日本の学生リーグでの実際の運用がどこにも書かれていない**。10件中、KCFA（関東学生連盟）のリーグ戦でタイブレークがどう使われているかに触れたページは0件。ほぼ全てがNFL基準か一般論。
2. **実例がない**。「どの試合が実際にタイブレークで決着したか」を記録つきで示したページが0件。
3. **タイブレークの得点が順位表・得失点差にどう反映されるかに触れたページが0件**。KCFA『順位順列決定方法』の「タイブレークでの得点は、順列決定に際しての得失点差には含まない」という規定は上位10件のいずれにも登場しない。

## 4. 本記事の差別化施策

- KCFA公式の試合結果PDF（`kcfa.jp/files/user/result_pdf/`）から、2023〜2025年度のTOP8・BIG8でタイブレーク決着となった**全6試合の延長スコア**を一次情報として掲載する（本サイトの`data/leagues/`から同点試合を抽出 → 各試合の公式PDFで延長得点を確認、という手順で作成）。
- KCFA『順位順列決定方法』の規定（タイブレーク得点は得失点差に含めない）と、本サイトの順位表・記録室の集計方法の対応関係を説明する。
- 一次データページへの内部リンク: TOP8/BIG8の順位表・日程・記録室・チームページ。

## 6. 注意点（執筆時の判断）

- 「何回目の超過節からトライフォーポイントの2点が必須になるか」は、日本語の解説サイト間で記述が割れており（3回目以降とするものが多い）、JAFA公式規則書の条文を直接確認できなかったため、**記事では規定として断定せず、公式記録に残る得点の事実のみを記述**した。
- 2019年秋季リーグ戦のKCFAレポートにもタイブレーク決着の記述があるが、対象校が本サイトのカバー範囲（TOP8・BIG8）外の可能性があるため、チーム名は出さずリンクのみ添えた。
