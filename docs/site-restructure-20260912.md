# 2026-09-12 サイト構成改善

ラクロスマニアの「試合を追う → リーグを探す → 過去の記録を調べる → 読みもの」という構成を、関東学生アメフトTOP8・BIG8へ適用。

- 全ページ共通メニュー：試合・結果、リーグ、読みもの、データベース、観戦ガイド、マイチーム。
- トップ：既存の提供画像を使い、ネイビーとゴールドのビジュアル、最新結果、次の日程、リーグカード、記録への入口を構成。
- データベース：2023〜2026年の既存データを年度・リーグ・大学で絞り込み。順位表をページ内に表示。BIG8の各ブロックを区別し、公式出典を付記。
- マイチーム：ブラウザに大学を保存、直近結果・次の試合・過去の記録へ接続。保存不可時も閲覧可能。
- 試合一覧：今後・終了・結果反映待ちを区別。タイブレークはスコア比較ではなく元データのwinnerを使用。
- 未公表の順位は「—」。既存URLと記事を維持。
- 実データのない動画・用語辞典の新規リンクは設置せず、既存の観戦ガイドへ接続。
- 協賛導線はアメフトマニア既存方針に従い未追加。

再生成：`python pipeline/generate_site.py`。追加依存なし。既存の毎日更新処理が新しい画面も生成する。

2026-09-12に本番反映の承認を受領。既存のGitHub Pages更新フローで公開する。
