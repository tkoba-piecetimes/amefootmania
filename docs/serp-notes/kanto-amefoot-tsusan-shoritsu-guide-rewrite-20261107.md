## 記事側の問題（確認した事実）
1. **「直近シーズン」が古い**: 本文の2026年度節は第1節（8/27〜9/6）の結果のみ。リポの `data/leagues/top8/standings.json` では2026年度TOP8は各校6試合消化（法政6-0、立教5-1、早稲田4-2、中央4-2、明治3-3、東京1-5、慶應1-5、日体大0-6）。通算表も「全81試合」＝2026年度第1節時点の値で止まっている。
2. **順列の決定基準を「星取表上では示されていない」と書いているが**、KCFAは「順位順列決定方法」 https://www.kcfa.jp/rankingmethod/ を公開しており、自媒体の `koshien-bowl-shutsujoko-kimekata` で6段階の基準を解説済み。記事内の記述が自媒体内で食い違っている。
3. **「星取表に引き分けの区分がない」**: KCFAの順位順列決定方法は勝ち3・引き分け1・負け0の勝ち点制で、`standings.json` にも draws 列がある。「リーグ戦の同点は規則上タイブレークで決着するため、実際の記録に引き分けが出ていない」という書き方への訂正が必要（要確認：rankingmethod ページと星取表の実際の列）。
4. 自媒体の関連記事 `amefoot-tiebreak-rule-guide`（タイブレーク実例6試合）、`koshien-bowl-shutsujoko-kimekata`（順列6基準）、`kanto-amefoot-heikin-tokuten-shitten-ranking` へのリンクがない。
