## 一次情報の確認（日本アメリカンフットボール協会 公式規則書 2026〜27年度版 第3章第1条第3条「超過節」）
- PDF: https://americanfootball.jp/wp-content/uploads/アメフト公式ルールブック2026-2027_軽量.pdf （FR-58〜59）
- 第4節終了時に同点のとき、JAFAが制定するタイ・ブレイク・システムを「行うことができる」。採用する場合は少なくとも試合前日までに主催者から両チームと審判員に通知
- コイントスの勝者は「オフェンスかディフェンスか」または「どちら側のフィールドで行うか」のどちらかを選ぶ。敗者は最初の超過節で残りを選び、以降は偶数番目の超過節で先に選択
- 超過節は表・裏2つのポゼッションシリーズ。相手の25ヤードラインから開始
- 各チームは得点するか、新たな第1ダウンの獲得に失敗するまでボールを所有
- 2回目の超過節では、タッチダウンをしたチームは2点のトライをしなければならない（1点のトライは得点として認められない）
- 3回目以降の超過節では、各チームは3ヤードラインから2点トライの1プレーだけを行う
- 勝者は通常の4節と超過節の合計得点が多いチーム
- タイムアウト: 1回目・2回目の超過節に各1回、3回目以降は試合終了までに各1回。第4節までの残りは持ち越せない

- 2回目の2点トライ必須・3回目以降の3ヤード2点トライ方式を「規則書で確認を」と外に出していた（上位と並ぶ網羅性の穴）。公式規則書で確認できたため本文に書ける
- コイントスの選択肢とタイムアウトの扱いが無い
- 冒頭の「NFLのように先に得点した側がそのまま勝ち」はNFLのルール変更を踏まえると不正確になり得るため削る
