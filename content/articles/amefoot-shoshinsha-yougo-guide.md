アメフトを見始めると、実況や解説で「ダウン」「ニュートラルゾーン」「タッチバック」といった言葉が次々に出てきます。ルールを一度に覚えようとすると大変ですが、用語を場面ごとに整理して覚えておくと、試合の流れが追いやすくなります。この記事では、初心者がまず押さえたい用語を、日本アメリカンフットボール協会（JAFA）が公開している公式規則書（2026〜27年度版）の定義をもとに、場面別に解説します。試合の基本的な流れや試合時間については、[大学アメフトの試合時間とルール入門](../american-football-watching-guide/index.html)もあわせて参考にしてください。

規則書の定義は条文として書かれているため、ここでは意味が変わらない範囲で読みやすく言い換えています。条文そのものを確認したい場合は、記事末尾の出典から規則書を開けます。

## まず押さえる：攻撃と守備、ダウンの基本

試合を見るうえで最初の壁になるのが「ダウン」と「シリーズ」です。この2つがわかると、攻撃側が何をしようとしているのかが見えてきます。

| 用語 | 意味（規則書の定義にもとづく） |
| --- | --- |
| オフェンス | ボールを確保している（または、ボールが所属している）チーム |
| ディフェンス | オフェンスの相手チーム |
| ダウン | 正当なスナップまたはフリー キックで始まり、ボールがデッドになって終わるまでの、試合の単位 |
| シリーズ | スナップで始まる、4回までの連続したダウンのまとまり |
| シリーズ獲得線 | ボールの最先端から前方10ヤードの線。相手のエンドゾーンに入る場合は、ゴールラインがその線になる |
| 第1ダウン（ファーストダウン） | 新しいシリーズの最初のダウン。シリーズ獲得線の上かそれを越えてボールを確保すると、新しいシリーズが与えられる |
| ロス オブ ダウン | ダウンを繰り返す権利を失うこと |

つまり、攻撃側は4回のダウンの間に10ヤード進めば、新しいシリーズが与えられて攻撃を続けられます。第4ダウンが終わっても進めなかった場合、守備側に新しいシリーズが与えられて攻守交代になります。このため、第4ダウンでは「パントで陣地を変える」「フィールドゴールで得点を狙う」「攻撃を続ける」のどれを選ぶかが見どころになります。スペシャルチームの役割については、[アメフトのスペシャルチームの役割の記事](../amefoot-special-team-yakuwari-guide/index.html)で詳しく整理しています。

![4回のダウンのうちに10ヤード進めば新しいシリーズ。進めなければ攻守交代](diagram:amefoot-four-downs)

## 試合の開始地点：ライン、スナップ、ハドル

プレーが始まる直前の場面には、独特の用語が集中します。

| 用語 | 意味（規則書の定義にもとづく） |
| --- | --- |
| スクリメージ ライン | 各チームのゴールラインに最も近いボールの先端を通るヤードライン。ボールがレディ フォー プレーになったときに形成される |
| ニュートラル ゾーン | 2本のスクリメージ ラインの間の空間。幅はボールの長軸の長さ |
| スナップ | 片手または両手による迅速かつ連続的な動作で、地面にあるボールを後方へ手渡しまたはパスすること。ボールがスナッパーの手を離れた時点で終了し、その後ボールはライブになる |
| スナッパー | ボールをスナップするプレーヤー |
| ハドル | ボールがレディ フォー プレーになった後、スナップやフリー キックの前に、2人以上のプレーヤーが集合すること |
| シフト | スナップの前に、2人以上のオフェンスのプレーヤーが同時にポジションや姿勢を変えること |
| ハッシュ マーク | サイドラインから内側へ60フィート（約18.29m）の位置に引かれた2本の短い線。ボールはこの上またはその間からスナップされる |

ニュートラル ゾーンは、ボールの長さ分だけの狭い空間です。ボールが正当にスナップされたときに、ディフェンスのプレーヤーがニュートラル ゾーン内に入っている、あるいは越えている状態は、オフサイドの反則になります。反則の種類と処置については、[アメフトの反則一覧の記事](../amefoot-hansoku-ichiran-guide/index.html)にまとめています。

![スクリメージラインとニュートラルゾーン。スナップの瞬間にディフェンスがニュートラルゾーンに入っているとオフサイド](diagram:amefoot-scrimmage-neutral-zone)

また、オフェンスがスナップ前にそろって静止しなければならない決まりがあります。シフトの後は、すべてのオフェンスのプレーヤーが少なくとも1秒間は静止しなければならず、スナップ前にスナップ時の動きに類似した動作などをすると、フォルススタートの反則です。

## ボールの動き：パス、ファンブル、インターセプト

ボールがどのように動いたかによって、用語が変わります。

| 用語 | 意味（規則書の定義にもとづく） |
| --- | --- |
| ボール キャリア | ライブ ボールを確保しているランナー（ボールを持って走っているプレーヤー） |
| パサー | フォワード パスを投げるプレーヤー |
| フォワード パス | ボールがグラウンドや他のものに最初に当たった地点が、パサーが手を離した地点より前方にあるパス |
| バックワード パス | 上記以外のすべてのパス（後ろ向きや横向きのパス） |
| ファンブル | パス、正当なキック、成功した手渡し以外の行為で、プレーヤーがボールの確保を失うこと |
| マフ | ボールをキャッチまたはリカバーしようとしたが、できずにボールにタッチしたこと |
| インターセプト | 相手のパスまたはファンブルをキャッチすること |
| リカバー | グラウンドに当たった後もライブであるボールを、キャッチの要件を満たして確保すること |

ここで注意したいのは、「スナップ」自体がバックワード パスに分類されるという点です。スナッパーがボールを離した時点で、スナップはバックワード パスになります。また、フォワード パスかどうかが疑わしい場合、ニュートラル ゾーンまたはその手前で投げられたパスは、バックワード パスではなくフォワード パスとして扱われます。

キャッチが成立するための条件も定められています。空中のボールを手または腕でしっかりと支配し、身体のいずれかの部分がインバウンズのグラウンドに接触し、その後、通常の試合での行為を行う十分な時間ボールの支配を続けることなどが要件です。規則書には「疑わしい場合はキャッチ、インターセプト、リカバーではない」とも書かれています。パスの成否が議論になりやすいのは、この要件が複数あるためです。

## 得点に関する用語

得点は、次のように規則書で定められています。

| 得点の方法 | 点数 |
| --- | --- |
| タッチダウン | 6点 |
| フィールド ゴール | 3点 |
| セイフティ（相手に与える得点） | 2点 |
| 成功したトライ（タッチダウン） | 2点 |
| 成功したトライ（フィールドゴールまたはセイフティ） | 1点 |

![得点の種類と点数の一覧](diagram:amefoot-scoring)

- **タッチダウン**：ひとことで言えば、相手のゴールラインを越えてボールを持ち込むことです。規則書では、たとえば、ライブ ボールが相手のゴールラインの面を越えたとき、フィールドオブプレーから前進したボール キャリアが、ボールを正当に確保していた場合などに成立します。相手のエンドゾーンでフォワード パスをキャッチした場合も含まれます。
- **トライ**：タッチダウンの後に行うスクリメージ ダウンです。結果がタッチダウンなら2点、フィールドゴールまたはセイフティなら1点が与えられます。トライの後は、キックオフで試合が再開されます。
- **セイフティ**：攻められた側が、自分たちのゴールライン後方でボールがアウト オブ バウンズになった、あるいは自分たちの責任でゴールラインを越えたボールが自陣のエンドゾーンでデッドになった場合などに、相手に2点が入るプレーです。判断に迷う場合は、セイフティではなくタッチバックとされます。
- **タッチバック**：攻める側の責任でボールがゴールラインを越えてデッドになったときに宣告されます。タッチバックの後は、守備側のチームの20ヤードラインからスナップで再開します。ただし、キックオフなどのフリー キックがタッチバックになった場合は、25ヤードラインから再開します。

セイフティとタッチバックの違いは、ボールがゴールラインを越えた「責任」がどちらのチームにあるかで決まります。見た目が似ていても得点になるかどうかが変わるので、中級者への入口になる用語です。

## キックに関する用語

キックの用語は、スナップを使うかどうかで整理すると覚えやすくなります。

| 用語 | 意味（規則書の定義にもとづく） |
| --- | --- |
| キックオフ | 前後半の開始時、トライの後、成功したフィールドゴールの試みの後に行うフリー キック。プレース キックまたはドロップ キックで行う |
| パント | ボールを落下させ、地面に触れる前に蹴るキック |
| ドロップ キック | ボールを落下させ、地面に触れた直後に蹴るキック |
| プレース キック | ティーまたは地面に置いたボールを蹴るキック（味方が保持してもよい） |
| ホルダー | 地面やティー上のボールを保持するプレーヤー |
| フィールド ゴールの試み | プレース キックまたはドロップ キックで行われるスクリメージ キック |
| フェア キャッチ | レシーバーが有効なシグナルを出してキャッチすること。キャッチした地点でボールがデッドになり、レシーブ側のボールになる |

フェアキャッチのシグナルを出したレシーバーは、キックチームからタックルやブロックをされない代わりに、ボールを持ってどの方向へも3歩以上動けません。なお2026年度から、フェアキャッチの後にフィールドゴールの試み（フェア キャッチ キック）を選べる新しい規定が加わりました。2026年秋季公式戦から適用される変更です。

## 位置と区域の用語

| 用語 | 意味（規則書の定義にもとづく） |
| --- | --- |
| フィールド オブ プレー | 両サイドラインと両ゴールラインの内側の領域 |
| エンド ゾーン | フィールドの両端にある、ゴールライン、サイドライン、エンドラインで囲まれた長方形の区域 |
| インバウンズ | サイドラインとエンドラインで囲まれた区域 |
| アウト オブ バウンズ | その区域の外側と、サイドライン・エンドライン自体 |
| ラインマン | 自分のスクリメージ ライン上に正当に位置するAチームのプレーヤー |
| バック | ラインマン以外のAチームのプレーヤーで、最も近いラインマンの腰を通る垂直面より、頭や肩が後方にあるプレーヤー |

規則書では、両ゴールライン間は100ヤード、エンドラインはゴールラインの後方10ヤードと定められています。サイドラインやエンドライン自体も、アウト オブ バウンズに含まれます。

![フィールドの全体図。ゴールライン・エンドゾーン・サイドライン・ハッシュマークの位置](diagram:amefoot-field-lines)

なお、規則書では「Aチーム」「Bチーム」という呼び方も使われます。Aチームはボールをプレーに移すチーム、Bチームはその相手チームを指し、この呼称は次にボールがレディ フォー プレーになるまで維持されます。オフェンス・ディフェンスという呼び方とは、ボールを確保しているかどうかの考え方が少し違う点に注意してください。

## 用語を覚えるコツと、試合での確認方法

用語は、1語ずつ暗記するよりも、試合の中で「あ、今がこの場面だ」と確認しながら覚えるほうが定着しやすいと考えられます。次のような順で試してみてください。

1. **まずはダウンとシリーズ**：画面や会場の表示で「何ダウンか」「あと何ヤードか」を見る習慣をつけます。
2. **次に得点の種類**：タッチダウン、フィールドゴール、セイフティの3つを区別します。
3. **最後にキックの用語**：キックオフ、パント、フェアキャッチを、試合の中で見つけてみます。

関東学生アメフトのTOP8・BIG8では、[TOP8の日程・結果](../../top8/schedule/index.html)や[BIG8の日程・結果](../../big8/schedule/index.html)から試合を選べます。順位が気になる場合は、[TOP8の順位表](../../top8/standings/index.html)や[BIG8の順位表](../../big8/standings/index.html)、[TOP8の記録室](../../top8/records/index.html)でチームごとの成績を確認できます。リーグの仕組みは[TOP8・BIG8とは](../top8-big8-guide/index.html)も参考になります。

## まとめ

- 最初に覚えるべき用語は、**ダウン**（プレーの単位）と**シリーズ**（4回までの連続したダウン）です。10ヤード進むと新しいシリーズが与えられます。
- **ニュートラル ゾーン**と**スナップ**は、プレーの開始地点を示す用語で、オフサイドやフォルススタートの反則と結びついています。
- ボールの動きは、**フォワード パス・バックワード パス・ファンブル・インターセプト**で区別されます。
- 得点は、タッチダウン6点、フィールドゴール3点、セイフティ2点、トライ1点または2点です。
- **セイフティとタッチバック**は、ボールがゴールラインを越えた責任がどちらのチームにあるかで分かれます。
- 規則は毎年見直されます。2026年度の変更点を含め、最新の内容は規則書で確認してください。
