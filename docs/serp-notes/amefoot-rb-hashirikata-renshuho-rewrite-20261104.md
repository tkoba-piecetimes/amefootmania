## 事実確認
- 5-10-5 は NFL スカウティングコンバインの「20ヤードシャトル」（プロアジリティ）と同じ種目。中央からスタートし、片側へ5ヤード、反対側へ10ヤード、中央へ5ヤード戻る（Houston Texans / Philadelphia Eagles 公式サイトのコンバイン解説、TopEndSports）。
  → 記事は「中心のマーカーから左右に5m・反対側に10m」とメートル表記で配置説明が不正確、かつ「プロアジリティシャトル」を別ドリルとして並べていた。修正対象
- 3コーン（Lドリル）はコンバインの別種目。5ヤード間隔の3コーンをL字に置く
- JAFA の IB2022 国内選考でもプロアジリティが測定種目（5ヤード間隔の3本ラインの中央から開始）。自サイト amefoot-agility-training-shumoku に既出
