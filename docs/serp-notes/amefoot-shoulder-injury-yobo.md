# SERP分析メモ: アメフト 肩の怪我 予防 トレーニング（P11）

調査日: 2026-10-16（WebSearchのみ。上位ページ全文のWebFetchは未実施で、検索結果の要約レベルの所見）

- 共通点: 上位は肩の怪我予防を「筋力・柔軟性・ウォームアップ・保護具・タックル技術」で一般論としてまとめる記事や、医療機関・メディカルノート系の肩関節脱臼の解説。ラグビー等の海外論文も混在し、アメフト大学生部員に向けて症状別（脱臼・肩鎖関節・腱板）に整理した日本語記事は見当たらなかった。
- 欠けている要素: 部員が練習中に出会う場面（タックル・ブロック・転倒）と傷害の種類の対応づけ、競技中と練習中でリスクが異なるという疫学データ、違和感を覚えたときの報告・受診の線引き、関東TOP8・BIG8の試合間隔を踏まえた調整の視点。
- 差別化: 脳震盪・ACL・タックルフォームの既存記事と重ならないよう肩に特化。HSS Journal(2023)の疫学レビューと医療情報で裏取りし、診断・治療は断定せず受診を促す。一次データページ（順位表・日程）への内部リンクで連戦時期の確認導線を作る。
