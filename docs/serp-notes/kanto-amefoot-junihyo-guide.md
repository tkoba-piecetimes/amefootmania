## 2. 上位の共通点（＝検索意図の正解）

- 検索者が本当に欲しいのは「**いま何位か**」であり、正解ページはKCFA公式の星取表（`result_team`）1つに集約されている。
- そのため上位は「公式サイト」「公式SNS」「配信・日程サイト」に二分され、**解説記事はSERP上位にほぼ存在しない**（second-effortは甲子園ボウル出場回数の歴代ランキングで、順位表ではない）。
- 日程・結果・配信への需要が同時に発生している（amefootlive・spocaleが上位に来ている）。

## 3. 上位陣に欠けている要素（＝差別化点）

1. **星取表の列の意味を説明しているページが1つもない**。KCFA星取表の列は「勝・敗／勝ち点／順位／順列」の4つで、勝ち点の付与ルールも順列の決め方もこのページには書かれていない。規定は別ページ [KCFA｜順位順列決定方法](https://www.kcfa.jp/rankingmethod/) に分離しており、星取表からは辿りにくい。この2ページを突き合わせて解説した記事は検索上位に見当たらない。
2. **シーズン中は「順位」「順列」の欄が空欄になる**という実務上の落とし穴に触れたページがない。2026-09-13時点の実測でTOP8全8校の順位・順列欄が空欄（WebFetchで確認）。読者は勝ち点を自分で並べ替えて読む必要がある。
3. **TOP8とBIG8で順位表の形が違う**点の解説がない。2026年度BIG8はAブロック・Bブロック各5校の一次リーグ→二次上位／二次下位リーグへ分岐し、勝ち点・勝敗・得失点を持ち越す（[KCFA 2026-02-18発表](https://www.kcfa.jp/information/detail/id=9851)）。したがってBIG8の順位表は途中で2枚→2枚に組み替わる。
4. **得失点差の扱い**。KCFA星取表に得失点差の列はなく、本サイトが試合結果から集計した参考値を表示している。一方、順列の判定に使うのは「当該校間に限っての得失点差（タイブレーク得点を除く）」で、両者は別物。この違いを説明したページはない。
5. 一次データ（[TOP8 順位表](../../site/top8/standings/index.html)・[BIG8 順位表](../../site/big8/standings/index.html)）を自前で持つのは本サイトの優位点。解説記事から順位表・日程・記録室へ回遊させる導線を作れる。
