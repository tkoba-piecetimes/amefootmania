## 自記事の不足（リライト前）
1. タイトルに「出場校」とあるのにTOP8の所属8校が本文に無かった（BIG8のブロック分けだけ記載）→ 検索者の「何校？どこ？」に未回答。CTRと満足度の両方に効く主因

3. 2027年度以降のBIG8 9・10位自動降格、2026年度の二次リーグ特例（上下入替なし）に触れていない
4. TOP8上位3校＝全日本大学選手権の関東代表、BIG8には出場枠なし、という「違い」の核心が弱い
