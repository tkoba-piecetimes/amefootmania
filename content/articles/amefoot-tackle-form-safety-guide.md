「タックルは怖い」「正しいフォームを覚えないと怪我をしそう」と感じている新入部員や、お子さんが入部を検討している保護者の方は少なくないはずです。アメフトのタックルでは、頭を下げて当たらないこと、つまり「顔を上げて肩から入る」ことが安全の出発点とされています。この記事では、公益社団法人日本アメリカンフットボール協会（JAFA）の公表資料をもとに、その理由と手順、やってはいけない当たり方を整理します。

## この記事の結論

- 顔を上げて（ヘッズアップ）、頭頂部で相手に当たらない（JAFA「頚部外傷とその予防」）
- タックルの際は肩から入る。JAFAの安全対策ハンドブックは「ショルダータックリングの徹底」を挙げています
- 正しい当たり方を支える土台は、首と体幹の強化（安全対策ハンドブック、ガーディアンキャップ留意事項）

## 頭を下げて当たると何が起きるか

JAFAの安全対策ハンドブックによると、アメリカンフットボールでの頸髄損傷は、多くが頭を下げて頭頂部からヒットすることで発生するとされています。また、頸髄損傷はディフェンスの選手がタックルして受傷するケースが多いと説明されています。

同ハンドブックの説明では、顔を上げて相手を見ている状態では頸椎は正しいカーブを描き、衝撃をうまく分散してくれます。一方、タックルの際に頭が下がって頸椎の並び方がストレートになり、頭のてっぺんからぶつかると、頸椎の脱臼や骨折につながり、頸髄が損傷される場合があるとされています。

こうした事故は現在も起きています。JAFAが2026年8月25日付で出した[緊急告知](https://americanfootball.jp/wp-content/uploads/2026重大事故注意喚起文.pdf)によると、2026年は8月の時点で重大事故の報告が既に9件となり、2006年以降では最多となりました。内訳は急性硬膜下血腫4件、脳挫傷1件、内臓損傷2件、頚椎骨折2件で、急性硬膜下血腫の1件は死亡事故と報告されています。

## JAFAが最重要視する「ヘッズアップ」――頭から当たらないこと

JAFAが2024年1月1日付で公表した[「頚部外傷とその予防」](https://americanfootball.jp/top_news/150/)という一次情報では、正しいタックル技術においてもっとも重要な要素として「顔を上げた状態でのコンタクト（ヘッズアップ）」が挙げられています。指導者に対しては、選手が正しくヘッズアップした状態でヒットする基本技術を習得できるよう、具体的に促すことが求められています。

頭頂部でのヒットは極めて危険とされ、このような接触方法は相手選手だけでなく、ヒットした側の選手自身にも重大な負傷を引き起こす大きなリスクを伴うと説明されています。「頭から当たる方が強く当たれる」というイメージを持つ選手もいるかもしれませんが、これは技術的にも安全面でも誤りだという点を、まず正しく理解しておく必要があります。

## ショルダータックルの基本ステップ

以下は一般的な指導の流れで、細部はチームの指導者の指示に従ってください。

1. **構え**：一般的には、ボールキャリアに対して重心を落とし、下半身を安定させた姿勢をとります。
2. **間合いを詰める**：一般的には、正面から一直線に突っ込むのではなく、角度をつけて近づき、接触の直前に小さな歩幅で距離を詰めます。
3. **踏み込み（顔を上げる・肩から）**：一般的には、顔を上げて視線を相手から離さず、頭ではなく肩から入ります。
4. **ラップ**：一般的には、腕を巻きつけて相手を引き寄せ、当たった後もタックルを完了させます。
5. **足を動かし続ける**：一般的には、接触後も足を止めず、動かし続けます。

### 肩から入り、顔を上げたまま踏み込む

接触は頭からではなく肩（ショルダー）から入ります。踏み込みの間は顔を上げた状態を保ち、視線を相手から離さないことが、JAFAの示すヘッズアップの徹底につながります。肩まわりの負担については[アメフトの肩の怪我の予防ガイド](../amefoot-shoulder-injury-yobo-guide/index.html)も参考にしてください。

### 研究で示された、頭を下げないタックル指導の効果

USA Footballは2012年にHeads Up Football（HUF）というプログラムを策定し、その中にHeads Up Tackling（HUT）というタックル指導の指針が含まれています。この指導が国内でどう影響したかを調べた研究が、[体育学研究62巻2号（2017年）](https://www.jstage.jst.go.jp/article/jjpehss/62/2/62_16108/_article/-char/ja)に掲載されています。国内トップリーグ（Xリーグ）の4試合、計166タックルを分析したところ、HUTの指導後に頭を下げたタックルは有意に減り、タックルの有効性には影響が見られなかったと報告されています。

安全な当たり方は弱いタックルを意味するわけではない、という研究結果があります。ただし、これは限られた試合数での分析である点には留意が必要です。

## やってはいけない当たり方

JAFAの資料から読み取れる、避けたい当たり方は次のとおりです。

- **頭を下げて頭頂部から当たる**：「決して頭頂部で相手にヒットしないこと」とされています（「頚部外傷とその予防」、安全対策ハンドブック）
- **ヘルメットを武器のように使う**：安全対策ハンドブックは、ヘルメットを武器として使うと相手のみならず自分も怪我をすることがあると説明しています。ヘルメット自体の選び方は[アメフトのヘルメットの選び方](../amefoot-helmet-erabikata-guide/index.html)で整理しています
- **防具を頼ってヘッドダウンで当たる**：ガーディアンキャップに関する留意事項では、衝撃を吸収してくれるがゆえにヘッドダウンしてヘルメットから当たる間違った当たり方が散見されると指摘されています
- **練習でチームメイトの不意を突くタックルをする**：安全対策ハンドブックは、練習ではチームメイトの不意を突くようなブロック、タックルはしないよう求めています

## 頚部の強化とメディカルチェックも安全対策の一部

JAFAの資料では、フォームの習得と並んで首の筋力強化が重要な予防策として位置づけられています。頭が振られないよう、土台となる首をしっかり鍛えておくことが大切だという考え方です。具体的な鍛え方は[アメフトの首の鍛え方](../amefoot-kubi-kitaekata-guide/index.html)で解説しています。

ガーディアンキャップに関する留意事項では、脳振盪を予防するために現場で重要なこととして、次の4点が挙げられ、中でも特に重要なのは1と2とされています。

1. 首の筋力強化
2. 正しい当たり方のスキルの習得
3. （メンテナンスを含めた）適切な防具の装着
4. 脳振盪に関する正しい知識の学習

メディカルチェックについては、前述の緊急告知で、新入生のメディカルチェック（頭部MRIを含む）の実施が推奨されています。

なお、脳振盪の対応について、安全対策ハンドブック（2024年9月改訂版）は、国際スポーツ脳振盪会議（2022年）を改編した段階的復帰の手順を示しています。ヘッドギア（ガーディアンキャップ）の効果や脳振盪の症状・復帰の詳細については、[アメフトの脳震盪対策とヘッドギア｜JAFAの見解から考える](../amefoot-noshinto-headgear-guide/index.html)で別途整理していますので、あわせて確認してみてください。

安全対策ハンドブックは2018年2月初版で、2024年9月に改訂版が発行されています。

## 事故が起きやすい場面

安全対策ハンドブックは、頭部外傷（急性硬膜下血腫、脳振盪）が起こりやすい状況として、次の8項目を挙げています。

| 起こりやすい状況 | ハンドブックの説明 |
| --- | --- |
| 若年者 | 10代の選手に多い |
| 初心者 | 競技経験が浅い選手に多い。高校1年、大学1〜2年に多い |
| 夏季、特に夏合宿 | 重症事故（急性硬膜下血腫）は夏季、特に夏合宿中に集中している |
| 疲労時 | 疲労して集中力が低下するとリスクが高まる |
| 不意のタックル・ブロック | 衝撃に対する身体の準備が整っておらず、頭部が振られやすくなる |
| RB・WR・DBなどのスキルポジション | ボールへの意識が高まる分、不意の衝撃を受けやすくなる |
| 頭部を使ったヒット | 頭部が下がった姿勢や、故意に頭部を狙ったタックルは危険 |
| 脳振盪の多いチーム | 脳振盪が多いチームは、急性硬膜下血腫のリスクも高くなる |

また、緊急告知では、2006年以降に報告された重症頭部外傷（頭蓋内出血）38件（うち死亡4件）は、8月、下級生、人数の少ないチームに多い傾向があるとされています。夏場の注意点は[アメフトの夏合宿と熱中症の対策](../amefoot-gasshuku-necchusho-guide/index.html)も参考にしてください。

## 新入部員が最初に取り組むべきこと

JAFAの緊急告知では、新入生は上級生とは別メニューでまず体づくりを優先させ、上級生の強いヒットに耐えうる身体、特に首・体幹をつくることが示されています。フォームを頭で理解していても、それを支える身体ができていなければ、無理な当たり方になり怪我のリスクが高まる場合があります。

あわせて、同じ緊急告知では次の対応が挙げられています。

- 首の強度が不十分と思われる選手は、上級生が混在する試合にはできるだけ出場させない
- 新入生で未熟な選手は、チームの人数の事情があっても無理に試合には出さない

安全対策ハンドブックでも、フルコンタクトの練習を長時間続けないこと、フルコンタクトの練習では上級生が下級生の技量に合わせることが求められています。入部直後の流れは[アメフト初心者の入部ガイド](../amefoot-beginner-join-guide/index.html)も参考にしてください。

## 反則を避ける当たり方――ルール上も禁止されている接触

安全なタックルは、怪我の予防だけでなくルール順守にもつながります。相手の顔・ヘルメット・フェイスマスク・チンストラップ（あごひも）または首をつかんだり、ねじったり、引っ張ったりする行為は反則として禁止されています。また、頭頂部で相手を痛めつけるヒットをした場合、ターゲティングの反則となります（「頚部外傷とその予防」）。ヘッズアップを徹底し、肩から正しく入るフォームを身につけることは、こうした反則を避けることにも直結します。反則の種類は[アメフトの反則一覧](../amefoot-hansoku-ichiran-guide/index.html)でまとめています。

## よくある質問

### タックルが怖いときはどうすればいい？

怖さを一人で抱え込まず、指導者に伝えてください。JAFAの資料では、初心者は基礎体力の養成を優先し、コンタクトでは技量に応じた配慮をすることが求められています。顔を上げて肩から入る手順を、段階を踏んで身につけていく進め方が基本です。

### 首を痛めないためには？

JAFAの資料では、コンタクトの際に顔を上げること、タックルでは肩から入ること、頚部と体幹の筋力トレーニングを強化することが挙げられています。常に「頭から当たらない」意識を持つことが大切とされています。

### 1年生はいつから当たり練習をする？

何週間後から、といった基準は示されていません。JAFAの緊急告知では、新入生は上級生とは別メニューでまず体づくりを優先するとされています。当たり練習を始める時期はチームの方針によるため、所属チームの指導者の指示に従ってください。

### ガーディアンキャップを着ければ安全？

JAFAのガーディアンキャップ留意事項によると、脳振盪のリスクを減らすという医学的な根拠は今のところありません。同資料では、脳振盪の予防では首の筋力強化と正しい当たり方の習得が特に重要とされています。

## まとめ

アメフトのタックルでは、顔を上げて頭頂部で当たらないこと、肩から入ることが、JAFAの資料で一貫して示されている基本です。頭を下げて当たると、頸椎がまっすぐになって衝撃を分散しにくくなり、重い怪我につながる場合があるとされています。その土台となるのが首と体幹の強化で、新入部員はまず体づくりを優先し、コンタクトはチームの方針に従って段階的に進めることが求められています。不安なことは、所属チームの指導者に相談してください。
